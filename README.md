# Quote Catalog Service

Сервис каталога цитат на **Python + FastAPI** с потоковым импортом данных в **SQLite**.

## Возможности

- Импорт больших JSON-файлов (до 120 МБ) потоково, без загрузки целиком в память
- Хранение цитат в SQLite с перезаписью по `id` (первичный ключ)
- Автоматическое удаление записей, отсутствующих во входящем наборе данных
- Добавление и замена цитаты через витрину (`PUT /catalog/{quote_id}`)
- Снятие цитаты с публикации через витрину (`DELETE /catalog/{quote_id}`)
- Чтение цитаты читателем с обращением в каталог при промахе (`GET /quotes/{quote_id}`)
- Эксплуатационная сводка (`GET /stats`)
- Проверка здоровья сервиса
- Запуск в Docker
- Коллекция Postman и документация OpenAPI

## Требования

- Python 3.10+
- pip

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py --host 0.0.0.0 --port 8000
```

Параметры запуска:

| Аргумент | По умолчанию | Описание            |
|----------|--------------|---------------------|
| `--host` | `0.0.0.0`    | Адрес для привязки  |
| `--port` | `8000`       | Порт                |

Документация API (Swagger UI): `http://localhost:8000/docs`

## Запуск в Docker

```bash
docker build -t quote-catalog .
docker run -p 8000:8000 quote-catalog
```

## Тестирование

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты используют временную SQLite-базу и не затрагивают рабочую `quotes.db`.

## Postman

Готовая коллекция запросов — в файле `postman_collection.json`.

Импорт в Postman:

1. Откройте Postman → **Import** → выберите `postman_collection.json`.
2. В коллекции определена переменная `baseUrl` (по умолчанию `http://localhost:8000`).
3. Запустите сервис и выполняйте запросы.

## OpenAPI

OpenAPI-схема генерируется FastAPI автоматически:

- Интерактивная документация (Swagger UI): `http://localhost:8000/docs`
- Альтернативный интерфейс (ReDoc): `http://localhost:8000/redoc`
- Сырая OpenAPI-схема (JSON): `http://localhost:8000/openapi.json`

Схему можно импортировать в Postman: **Import → Link** → `http://localhost:8000/openapi.json`.

## Данные

### Источник цитаты

У каждой цитаты есть атрибут «источник» (`source`). Возможные значения:

- **`CATALOG`** — цитаты из удалённого источника данных (приходят через `POST /import`)
- **`LOCAL`** — цитаты, добавленные через `PUT /catalog/{quote_id}`

## API

### `GET /health`

Проверка здоровья сервиса. Всегда возвращает HTTP 200.

**Ответ:**
```json
{"status": "healthy"}
```

### `POST /catalog/source`

Сохраняет URL источника каталога в глобальную переменную.

**Тело запроса:**
```json
{"url": "http://catalog.internal:9000"}
```

**Ответ (HTTP 200):**
```json
{"source": "http://catalog.internal:9000"}
```

### `POST /import`

Потоковый импорт цитат в SQLite. Тело — большой JSON следующего формата:

```json
{"quotes": [
{"id": "q-0000001", "author": "Марк Аврелий", "text": "…", "tags": ["стоицизм"], "year": 170, "lang": "ru"},
{"id": "q-0000002", "author": "…", "text": "…", "tags": [], "year": 0, "lang": "ru"}
]}
```

Правила:

- Первая строка всегда `{"quotes": [`, последняя — `]}`.
- Каждая строка между ними — отдельный JSON-объект цитаты.
- Записи разделяются символом `,` в конце строки.
- Цитаты сохраняются с перезаписью по `id` (первичный ключ).
- Импортированные цитаты получают источник `CATALOG`.
- Если приходит цитата с id локальной записи (`LOCAL`), она замещается снимком, что считается вытеснением (eviction).
- Записи из БД, чьих `id` нет во входящем наборе, удаляются.

**Ответ (HTTP 200):**
```json
{"imported": 340000, "dropped": 120}
```

Где `imported` — число импортированных цитат, `dropped` — число удалённых.

### `PUT /catalog/{quote_id}`

Добавляет или заменяет одну цитату через витрину. `quote_id` — id записи в таблице БД. Добавленная цитата получает источник `LOCAL`.

**Тело запроса:**
```json
{"author": "Марк Аврелий", "text": "…"}
```

Ограничения полей:

- `author` — от 1 до 200 знаков
- `text` — от 1 до 16384 знаков

**Ответ (HTTP 200):**
```json
{"id": "q-0000001", "author": "Марк Аврелий", "text": "…"}
```

Запись актуальна по определению: читателю она отдаётся сразу после ответа, перечитывать её из каталога не нужно. Нарушение границ полей — **HTTP 422**.

### `DELETE /catalog/{quote_id}`

Снимает цитату с публикации через витрину. Запись **не удаляется**, а помечается как снятая с публикации. `quote_id` — id записи в таблице БД.

**Ответ (HTTP 200):**
```json
{"deleted": true}
```

**Ответ (HTTP 404), если запись не найдена:**
```json
{"detail": "not found"}
```

Снятая цитата читателям не отдаётся, даже если в каталоге она ещё есть, — до следующего снимка.

### `GET /quotes/{quote_id}`

Чтение цитаты читателем. Ответ содержит запись целиком — все поля, которые были у неё в снимке или в ответе каталога.

Сначала витрина ищет цитату у себя (только опубликованные). Если не нашла — обращается в каталог по адресу, заданному через `POST /catalog/source`.

**Ответ (HTTP 200):**
```json
{"id": "q-0000001", "author": "Марк Аврелий", "text": "…", "tags": ["стоицизм"], "year": 170, "lang": "ru"}
```

Ответ 200 обязан содержать заголовок **`X-Source`**:

- `LOCAL` — отдано из того, что витрина держит у себя
- `CATALOG` — за этим ответом витрина обращалась в каталог

**Ответ (HTTP 404), если цитаты нет ни у витрины, ни в каталоге:**
```json
{"detail": "not found"}
```

Что цитаты нет, витрина не запоминает: редакция заводит их постоянно, и читатель, пришедший по свежей ссылке, обязан увидеть цитату сразу.

### `GET /stats`

Эксплуатационная сводка. Все величины — с момента старта процесса, только растут (кроме `local`, `bytes` и `catalog`).

**Ответ (HTTP 200):**
```json
{
  "served_local": 10423,
  "served_from_catalog": 512,
  "catalog_reads": 96,
  "evictions": 148,
  "local": 63,
  "bytes": 516159,
  "catalog": 340000
}
```

| Поле                 | Значение                                                                 |
|----------------------|--------------------------------------------------------------------------|
| `served_local`       | сколько ответов читателям витрина отдала, не обращаясь в каталог          |
| `served_from_catalog`| сколько ответов читателям потребовали обращения в каталог                |
| `catalog_reads`      | сколько запросов витрина отправила в каталог                             |
| `evictions`          | сколько записей витрина удалила у себя, не считая ушедших из снимка      |
| `local`              | сколько записей витрина держит наготове сейчас                            |
| `bytes`              | сколько байт они занимают сейчас                                          |
| `catalog`            | сколько цитат витрина знает сейчас                                        |

`served_from_catalog` и `catalog_reads` считаются независимо друг от друга и совпадать не обязаны.

## Обработка ошибок

- **HTTP 400** — невалидный JSON в теле запроса (в том числе некорректная структура тела `/import`)
- **HTTP 404** — запись не найдена (например, `DELETE /catalog/{quote_id}`, `GET /quotes/{quote_id}`)
- **HTTP 422** — нарушение границ полей, прочие ошибки валидации параметров
- **HTTP 502** — каталог недоступен или вернул неожиданный ответ при чтении цитаты
